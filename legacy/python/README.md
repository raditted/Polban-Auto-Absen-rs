# Legacy Python (v2.0)

Folder ini adalah arsip implementasi Python (`auto_absen.py` + `tui.py`) sebelum rewrite ke **Rust v3.0** (`crates/absen-core` + `crates/absen-cli`).

- Tidak lagi dirawat atau dipakai oleh launcher utama (`windows/`, `linux/`, `termux/`).
- Disimpan sebagai referensi historis dan pembanding paritas perilaku.
- Untuk menjalankan versi aktif tanpa runtime eksternal, gunakan binary `polban-absen` dari GitHub Releases atau build dengan `cargo build --release --bin polban-absen`.
